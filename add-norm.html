Section 3.1 · the glue between sub-layers

The Add & Norm sublayer

Every box in the Transformer diagram labelled "Add & Norm" is two operations stacked: a residual connection that adds the sub-layer's input back to its output, then layer normalization. In symbols, the output of each sub-layer is LayerNorm(x + Sublayer(x)). It carries no understanding of language — its only job is to make a deep stack of attention and feed-forward blocks trainable.

01 Two jobs, one box

the Add — residual

A gradient highway

The skip path x + Sublayer(x) lets gradients flow straight back through dozens of layers without vanishing. Each sub-layer only has to learn a correction to its input, not rebuild it from scratch.

the Norm — LayerNorm

A scale tamer

Re-centers and re-scales each token vector so its features have mean 0 and variance 1, then applies learnable γ and β. Activations stay in a healthy range layer after layer.

Why it matters: the original Transformer is 6 encoder + 6 decoder layers, each with two sub-layers — over two dozen stacked non-linear blocks. Without residuals the gradient signal dies before it reaches the early layers; without normalization the activation magnitudes drift and training diverges. Add & Norm is what keeps the whole tower stable.

01·b Where it sits in a block

one encoder layer · two Add & Norm boxes
x [B, T, D] → Self-Attn → Add&Norm → Feed-Fwd → Add&Norm → out [B, T, D]

Both attention and the feed-forward network are wrapped by their own Add & Norm. The shape [B, T, D] is preserved end to end — addition and normalization never change dimensionality, which is exactly why d_model is kept constant across the whole model.

The one thing to remember: the sub-layer never has to reproduce its input — the skip rail already carries x forward. The sub-layer only learns a small update, the Add merges it in, and LayerNorm rescales the result so the next box receives clean activations. Use ← / → to step.
Vaswani et al. · 2017

One line, two operations

The paper states it in a single sentence: "the output of each sub-layer is $\mathrm{LayerNorm}(x + \mathrm{Sublayer}(x))$, where $\mathrm{Sublayer}(x)$ is the function implemented by the sub-layer itself." Read it inside-out.

$$\text{out} = \mathrm{LayerNorm}\big(\underbrace{x}_{\text{residual}} + \underbrace{\mathrm{Sublayer}(x)}_{\text{attn or FFN}}\big)$$
read it inside-out
  • Sublayer(x)  run multi-head attention or the feed-forward net on the input.
  • x + …  Add — the residual / skip connection puts the original input back.
  • LayerNorm(…)  Norm — normalize the summed vector across its features.

02 LayerNorm, expanded

LayerNorm (Ba, Kiros & Hinton, 2016) normalizes each token over its $D$ feature dimensions — independent of the batch and of other tokens. Mean and variance are computed per row; two learnable vectors $\gamma$ (scale) and $\beta$ (shift) restore expressivity.

$$\mu = \frac1D\sum_{j=1}^{D} x_j, \qquad \sigma^2 = \frac1D\sum_{j=1}^{D} (x_j-\mu)^2$$ $$\mathrm{LayerNorm}(x)_j = \gamma_j \cdot \frac{x_j - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta_j$$
the whole sublayer in PyTorch 
class AddNorm(nn.Module):
    def __init__(self, d_model, dropout=0.1):
        super().__init__()
        self.norm = nn.LayerNorm(d_model)      # learns γ, β of size [D]
        self.drop = nn.Dropout(dropout)

    def forward(self, x, sublayer):
        # Post-LN, as in the 2017 paper
        return self.norm(x + self.drop(sublayer(x)))
The $\epsilon$: a tiny constant (e.g. 1e-5) added under the square root so we never divide by zero when a token's features happen to be (nearly) constant.
Dropout detail: the paper applies dropout to each sub-layer's output before it is added to the residual and normalized — that's the drop(sublayer(x)) above, not drop(x).
The skip connection

Add — the gradient highway

Stacking many layers normally makes the backward gradient shrink (or blow up) geometrically with depth — the vanishing gradient problem. A residual connection changes each layer's Jacobian from $J$ to $I + J$: the identity term $I$ guarantees a path of magnitude 1 straight to the input. Slide depth and per-layer gain below and watch the two regimes diverge.

$$\frac{\partial\,\text{out}}{\partial x} = \underbrace{I}_{\text{skip}} + \underbrace{\frac{\partial\,\mathrm{Sublayer}(x)}{\partial x}}_{J} \;\;\Longrightarrow\;\; \text{gradient} \sim (1+g)^{N}\ \text{instead of}\ g^{N}$$
gradient magnitude vs depth · log scale

Each layer multiplies the back-flowing gradient by roughly its Jacobian norm g. The rose curve is a plain stack (factor g per layer); the emerald curve adds a residual (factor 1 + g).

Read it: when g < 1 the plain gradient collapses toward zero by the bottom layer — early weights barely update. The residual factor 1 + g stays above 1, so the signal survives the full depth. That surviving path is the "highway."
Intuition: a residual block only needs to learn the difference between its input and the desired output (Sublayer(x) = out − x). Learning a small correction is far easier than relearning the whole signal — which is why a near-zero sub-layer at init still passes the input through cleanly.
Per-token feature normalization

Norm — flatten then reshape

LayerNorm takes one token's $D$ features, subtracts their mean and divides by their standard deviation — so whatever goes in comes out with mean 0 and variance 1. The invariance is the point: push gain and bias to any extreme — the middle (normalized) strip is unchanged, and norm mean stays 0 while norm std stays 1. LayerNorm erases the per-token scale and offset, so the next sub-layer always receives activations in the same well-behaved range.

  • B (batch) and T (seq length) never enter the statistics — that's the key difference from BatchNorm, which pools down the batch/token axis.

05·c LayerNorm vs BatchNorm

LayerNorm — used here

Across features

Normalizes over the $D$ axis, per token. No dependence on batch size or other examples — so it behaves identically at train and inference, and works with variable-length sequences.

BatchNorm — not used

Across the batch

Normalizes each feature over the batch. Unstable for short/variable sequences and small batches, and needs running statistics at inference — a poor fit for sequence models, hence LayerNorm.

Where does the Norm go?

Post-LN vs Pre-LN

The 2017 paper puts LayerNorm after the residual add — Post-LN. Later work found that moving it inside the residual branch, before the sub-layer — Pre-LN — trains far more stably and usually removes the need for a learning-rate warm-up. Almost every modern LLM (GPT-2 onward) uses Pre-LN.

Norm sits inside the branch — the skip path stays a clean, un-normalized identity stream.
Why Pre-LN is steadier: the residual stream is never re-normalized, so the identity highway runs unobstructed from the last layer to the first — gradients reach early layers at full strength. Post-LN's gradients can grow with depth, which is why the original Transformer needed a careful warm-up schedule.
Trade-off: well-tuned Post-LN can reach slightly better final quality, but it is finicky to train deep. Pre-LN is the robust default; some recipes (e.g. DeepNorm) re-engineer Post-LN to scale to hundreds of layers.

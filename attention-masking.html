Masking in
Attention

Attention lets every token look at every other token — but sometimes it mustn't. Masking adds $-\infty$ to forbidden scores so softmax zeroes them out: no peeking at the future, no attending to padding. Flip the masks live below, then prove it on the Practice tab.

01 Why mask at all?

Scaled dot-product attention, with a mask the core formula

Every query scores every key, we scale by $\sqrt{d_k}$, softmax into weights, and mix the values. The mask $M$ is added to the scores before softmax.

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)V$$
$M_{ij} = 0$ if query $i$ may attend to key $j$,   $M_{ij} = -\infty$ if it may not.
The whole trick in one line: $\text{softmax}(\dots + (-\infty)) \to 0$. Adding $-\infty$ to a score makes its $e^{-\infty}=0$, so that key receives exactly zero attention weight — and contributes nothing to the output. Allowed positions are untouched ($+0$).

Two masks you actually use

Causal / look-ahead mask
Hides future tokens in decoder self-attention.
Lower-triangular: token $i$ sees only $j \le i$.
# so generation can't cheat by reading ahead
Padding mask
Hides <pad> tokens added to batch shorter
sequences to equal length.
# so meaningless padding gets no attention
They compose: a decoder processing a padded batch uses both (causal AND padding) at once — a position is allowed only if it passes both tests.

Where it lives in the paper

Vaswani et al. (2017), §3.2.3:

“We implement this inside scaled dot-product attention by masking out (setting to −∞) all values in the input of the softmax which correspond to illegal connections.”

# the decoder's masked multi-head self-attention is
# the only sub-layer that needs the causal mask.

In code — masked_fill before softmax

scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k) # [B,H,T,T]
scores = scores.masked_fill(mask, float('-inf')) # forbidden → −∞
attn = scores.softmax(dim=-1) # forbidden → 0
out = attn @ V # mix only allowed values
Why add, not multiply? Multiplying weights by 0 after softmax would break normalisation (rows wouldn't sum to 1). Adding $-\infty$ before softmax removes those keys from the competition, so the remaining weights still sum to 1.

03 Causal mask — no peeking ahead

Lower-triangular by design decoder self-attention

When a language model predicts token $i{+}1$ from tokens $\le i$, position $i$ must not see anything to its right. The mask allows key $j$ only when $j \le i$ — a lower-triangular pattern.

$$M^{\text{causal}}_{ij} = \begin{cases} 0 & j \le i \quad(\text{past or self}) \\ -\infty & j > i \quad(\text{future}) \end{cases}$$
# build it once, reuse every step
mask = torch.triu(torch.ones(T, T), diagonal=1).bool()
# triu(…, diagonal=1) = strictly-upper triangle = the future = True (masked)

04 Padding mask — ignore the filler

Batches need equal length encoder & decoder

To batch sentences of different lengths we pad the short ones with a special <pad> token. Those positions carry no meaning, so every query must give them zero attention — mask out the padded key columns.

$$M^{\text{pad}}_{ij} = \begin{cases} 0 & \text{key } j \text{ is a real token} \\ -\infty & \text{key } j \text{ is } \texttt{} \end{cases}$$
Padding masks whole columns $j$ — independent of the query row $i$.
# key_padding_mask: True where the token is padding
pad = (tokens == PAD_ID) # [B, T]
scores = scores.masked_fill(pad[:, None, None, :], float('-inf'))

05 In multi-head attention

One mask, broadcast to every head [B, H, T, T]

Multi-head attention runs $H$ attention computations in parallel on different projections of $Q,K,V$. The scores have shape $[B, H, T, T]$ — but the mask is the same $[T,T]$ pattern, broadcast across the batch and head dimensions.

$$\text{scores}: [B, H, T, T] \;+\; \underbrace{M}_{[1,\,1,\,T,\,T]} \;\Rightarrow\; \text{same legality for all heads}$$
Broadcasting copies the one mask over the $B$ and $H$ axes — you never build $H$ separate masks.
Heads differ in content, not in legality. Each head learns to attend to different relationships, but which positions are even allowed is identical — the future is the future for every head.

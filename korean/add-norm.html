Add & Norm 서브레이어

트랜스포머 다이어그램에서 "Add & Norm" 이라고 적힌 모든 박스는 두 연산이 겹쳐진 것입니다: 서브레이어의 입력을 출력에 다시 더하는 잔차 연결(residual connection), 그리고 레이어 정규화(layer normalization). 기호로 쓰면 각 서브레이어의 출력은 LayerNorm(x + Sublayer(x)) 입니다. 언어를 이해하는 부분은 아니고 — 어텐션과 피드포워드 블록을 깊게 쌓아도 학습이 되도록 만드는 것이 유일한 역할입니다.

01 한 박스, 두 가지 임무

Add — 잔차

그래디언트 고속도로

스킵 경로 x + Sublayer(x) 덕분에 그래디언트가 수십 개 레이어를 거쳐도 소실되지 않고 곧장 거꾸로 흐릅니다. 각 서브레이어는 입력을 처음부터 다시 만들 필요 없이 보정값만 학습하면 됩니다.

Norm — LayerNorm

스케일을 길들이는 장치

각 토큰 벡터를 다시 중심화·재스케일하여 피처들이 평균 0, 분산 1이 되게 한 뒤, 학습 가능한 γ와 β를 적용합니다. 레이어를 거듭해도 활성값이 건강한 범위에 머뭅니다.

왜 중요한가: 원본 트랜스포머는 인코더 6 + 디코더 6 레이어이고 각각 서브레이어가 2개라 — 스무 개가 넘는 비선형 블록이 쌓여 있습니다. 잔차가 없으면 그래디언트 신호가 앞쪽 레이어에 닿기도 전에 죽고, 정규화가 없으면 활성값 크기가 흘러가 학습이 발산합니다. Add & Norm이 이 거대한 탑 전체를 안정적으로 유지합니다.

한 박스, 한 단계씩

"Add & Norm"이 실제로 무엇을 하는지 아직 흐릿한가요? 토큰 벡터 하나를 박스에 단계별로 통과시키며 각 연산을 지켜보세요. 오른쪽의 청록색 레일이 잔차 / 스킵입니다 — 입력을 서브레이어를 우회해 앞으로 복사한 뒤 Add에서 다시 합칩니다. 이 우회 복사가 핵심 전부입니다.

한 줄, 두 연산

논문은 이걸 한 문장으로 말합니다: "각 서브레이어의 출력은 $\mathrm{LayerNorm}(x + \mathrm{Sublayer}(x))$이며, 여기서 $\mathrm{Sublayer}(x)$는 서브레이어 자체가 구현하는 함수다." 안쪽부터 바깥쪽으로 읽어보세요.

$$\text{out} = \mathrm{LayerNorm}\big(\underbrace{x}_{\text{residual}} + \underbrace{\mathrm{Sublayer}(x)}_{\text{attn or FFN}}\big)$$
안쪽부터 읽기
  • Sublayer(x)  입력에 멀티헤드 어텐션 또는 피드포워드 네트워크를 실행합니다.
  • x + …  Add — 잔차 / 스킵 연결이 원래 입력을 다시 더합니다.
  • LayerNorm(…)  Norm — 합쳐진 벡터를 피처 축으로 정규화합니다.

02 LayerNorm, 풀어쓰기

LayerNorm (Ba, Kiros & Hinton, 2016)은 각 토큰을 그 토큰의 $D$개 피처 차원에 대해 정규화합니다 — 배치나 다른 토큰과는 무관하게요. 평균 과 분산은 행(row)마다 계산되고, 학습 가능한 두 벡터 $\gamma$(스케일)와 $\beta$(시프트)가 표현력을 되살립니다.

$$\mu = \frac1D\sum_{j=1}^{D} x_j, \qquad \sigma^2 = \frac1D\sum_{j=1}^{D} (x_j-\mu)^2$$ $$\mathrm{LayerNorm}(x)_j = \gamma_j \cdot \frac{x_j - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta_j$$
서브레이어 전체를 PyTorch로 
class AddNorm(nn.Module):
    def __init__(self, d_model, dropout=0.1):
        super().__init__()
        self.norm = nn.LayerNorm(d_model)      # [D] 크기의 γ, β 학습
        self.drop = nn.Dropout(dropout)

    def forward(self, x, sublayer):
        # 2017 논문대로 Post-LN
        return self.norm(x + self.drop(sublayer(x)))
$\epsilon$ 은: 제곱근 안에 더하는 아주 작은 상수(예: 1e-5)로, 어떤 토큰의 피처가 (거의) 일정할 때도 0으로 나누는 일이 없게 합니다.
드롭아웃 디테일: 논문은 각 서브레이어의 출력에, 잔차에 더해 정규화되기 전에 드롭아웃을 적용합니다 — 위의 drop(sublayer(x))이지 drop(x)가 아닙니다.
스킵 연결

Add — 그래디언트 고속도로

레이어를 많이 쌓으면 보통 역방향 그래디언트가 깊이에 따라 기하급수적으로 작아지거나(혹은 폭발하는) — 그래디언트 소실(vanishing gradient) 문제가 생깁니다. 잔차 연결은 각 레이어의 야코비안을 $J$에서 $I + J$로 바꿉니다: 항등 항 $I$가 입력까지 곧장 이어지는 크기 1의 경로를 보장합니다. 아래에서 깊이와 레이어별 게인을 움직여 두 양상이 갈라지는 걸 보세요.

$$\frac{\partial\,\text{out}}{\partial x} = \underbrace{I}_{\text{skip}} + \underbrace{\frac{\partial\,\mathrm{Sublayer}(x)}{\partial x}}_{J} \;\;\Longrightarrow\;\; \text{gradient} \sim (1+g)^{N}\ \text{instead of}\ g^{N}$$
그래디언트 크기 vs 깊이 · 로그 스케일

각 레이어는 거꾸로 흐르는 그래디언트에 대략 야코비안 노름 g를 곱합니다. 분홍색 곡선은 잔차 없는 스택(레이어당 계수 g), 에메랄드 곡선은 잔차를 더한 경우(계수 1 + g)입니다.

해석: g < 1이면 잔차 없는 그래디언트는 맨 아래 레이어에 가면 0으로 무너집니다 — 앞쪽 가중치가 거의 업데이트되지 않죠. 잔차 계수 1 + g는 항상 1 이상이라 신호가 전체 깊이를 살아서 통과합니다. 그 살아남는 경로가 "고속도로"입니다.
직관: 잔차 블록은 입력과 원하는 출력 사이의 차이만 학습하면 됩니다 (Sublayer(x) = out − x). 작은 보정을 배우는 게 신호 전체를 다시 배우는 것보다 훨씬 쉽습니다 — 그래서 초기화 직후 서브레이어가 거의 0이어도 입력이 깔끔하게 그대로 통과합니다.
토큰별 피처 정규화

Norm — 평탄화 후 재구성

LayerNorm은 토큰 하나의 $D$개 피처를 가져와 평균을 빼고 표준편차로 나눕니다 — 그래서 무엇이 들어오든 평균 0, 분산 1로 나옵니다. 아래에서는 고정된 피처 패턴을 여러분이 조절하는 gain과 bias에 통과시킵니다. 원본(raw) 막대는 크게 요동치는데 정규화된 출력은 꿈쩍도 안 하는 걸 보세요 — 그다음 γ와 β로 의도적으로 재구성해 보세요.

핵심은 불변성: gain과 bias를 아무리 극단으로 밀어도 — 가운데(정규화) 띠는 그대로이고, 정규화 평균은 0, 정규화 표준편차는 1을 유지합니다. LayerNorm은 토큰별 스케일과 오프셋을 지워버려, 다음 서브레이어는 항상 똑같이 잘 다듬어진 범위의 활성값을 받습니다.

05·b 어느 슬라이스가 정규화되나?

트랜스포머 활성값은 [B, T, D] 큐브입니다 — 배치 안에 B개 시퀀스, 각 시퀀스마다 T개 토큰, 토큰마다 D개 피처. LayerNorm은 D축으로 reduce합니다: 모든 토큰이 자기만의 평균·표준편차로 독립적으로 정규화됩니다. 슬라이더로 슬라이스를 고르고 토글을 눌러, BatchNorm이라면 대신 배치/토큰 축으로 reduce하는 모습을 보세요.

LayerNorm은 마지막 축 D만 reduce합니다 — 토큰당 한 번:
[B, T, D] B = 배치 · T = 시퀀스 길이 · D = d_model 토큰 (b,t): [ x₀ x₁ … x_D-1 ] ──D축으로 reduce──▶ μ(b,t), σ(b,t) y = (x − μ) / √(σ² + ε) · γ + β → 모양 그대로 [B, T, D]
  • μ, σ는 b, t 인덱스만 가짐 (j 없음) → 토큰당 1쌍 → 총 B×T쌍 (여기선 1 × 10 = 10번 정규화).

  • 코드: nn.LayerNorm(d_model)은 마지막 차원만 reduce.

05·c LayerNorm vs BatchNorm

LayerNorm — 여기서 사용

피처 축으로

$D$축으로, 토큰마다 정규화합니다. 배치 크기나 다른 예시에 의존하지 않아 — 학습과 추론에서 동일하게 동작하고, 길이가 제각각인 시퀀스에서도 잘 작동합니다.

BatchNorm — 사용 안 함

배치 축으로

각 피처를 배치에 대해 정규화합니다. 짧거나 가변 길이 시퀀스, 작은 배치에서 불안정하고 추론 시 이동 통계가 필요해 — 시퀀스 모델엔 잘 안 맞습니다. 그래서 LayerNorm을 씁니다.

Norm은 어디에 들어가나?

Post-LN vs Pre-LN

2017 논문은 LayerNorm을 잔차 덧셈 뒤에 둡니다 — Post-LN. 이후 연구에서 이를 잔차 분기 안쪽, 서브레이어 앞에 두는 Pre-LN이 훨씬 안정적으로 학습되고 보통 학습률 워밍업이 필요 없다는 게 밝혀졌습니다. 현대의 거의 모든 LLM(GPT-2 이후)이 Pre-LN을 씁니다.

Norm이 분기 안쪽에 있음 — 스킵 경로는 정규화되지 않은 깨끗한 항등 스트림으로 유지됨.
Pre-LN이 더 안정적인 이유: 잔차 스트림이 다시 정규화되지 않아, 항등 고속도로가 마지막 레이어부터 첫 레이어까지 막힘없이 이어집니다 — 그래디언트가 앞쪽 레이어까지 온전한 세기로 도달하죠. Post-LN의 그래디언트는 깊이에 따라 커질 수 있어서, 원본 트랜스포머는 세심한 워밍업 스케줄이 필요했습니다.
트레이드오프: 잘 튜닝된 Post-LN은 최종 품질이 약간 더 좋을 수 있지만 깊게 학습하기 까다롭습니다. Pre-LN이 견고한 기본값이고, 일부 기법(예: DeepNorm)은 Post-LN을 다시 설계해 수백 레이어까지 확장합니다.

+

Add는 절대 안 변함

잔차 / 스킵 연결은 모든 변형에 들어 있습니다. 타협 불가능한 그래디언트 고속도로죠.

μ

평균은 선택

RMSNorm은 μ 빼기와 β 시프트를 버립니다 — 그냥 제곱평균제곱근으로 나누고 γ로 스케일.

α

잔차를 스케일

DeepNorm은 스킵 경로에 상수 α를 곱해, 아주 깊은 Post-LN 스택도 안정적으로 유지합니다.

$$\mathrm{RMSNorm}(x)_j = \gamma_j \cdot \frac{x_j}{\sqrt{\tfrac1D\sum_k x_k^2 + \epsilon}} \qquad\text{(}\mu\text{ 없음, }\beta\text{ 없음)}$$

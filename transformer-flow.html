The Transformer
architecture

Introduced in "Attention Is All You Need" (Vaswani et al., 2017), the Transformer replaced recurrence with self-attention, enabling full parallelism and long-range dependencies. Every tensor that flows through the model keeps the same embedding width D = 512, making residual connections simple and deep stacking clean.

Hyperparameters (base model)

Embedding Dim
d_model = 512

Width of every tensor flowing through the model. All residual paths maintain this exact dimension.

Attention Heads
h = 8 heads d_k = d_v = 64

d_k = d_model / h = 512 / 8 = 64. Each head sees a 64-dim projection of Q, K, and V.

FFN Inner Dim
d_ff = 2048

4× expansion inside the feed-forward block. The bottleneck compresses back to 512 with W₂.

Encoder/Decoder Depth
N = 6 layers

Six identical layers stacked. Each layer applies attention + FFN with residual connections.

Dropout
p = 0.1

Applied after each sub-layer output, after attention weights, and at embedding input.

Vocab / Sequence
vocab ≈ 37k max_len = 512

BPE vocabulary shared between source/target. Sinusoidal PE supports up to max_len positions.

Key insight: Every sub-layer output (attention, FFN) has the same shape (B, S, 512), so residual connections always add tensors of identical shape — no projection needed.
Weight sharing: The source embedding matrix, target embedding matrix, and pre-softmax linear share the same weights, scaled by √d_model.

Encoder tensor flow

The encoder maps a source sequence of token IDs into a rich context representation. Each of the 6 layers refines the representation through self-attention (every position attends to every other) and a position-wise feed-forward network.

PyTorch — one encoder layer

import torch
import torch.nn as nn

class EncoderLayer(nn.Module):
    def __init__(self, d_model=512, nhead=8, d_ff=2048, dropout=0.1):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(d_model, nhead, dropout=dropout, batch_first=True)
        self.ff1   = nn.Linear(d_model, d_ff)
        self.ff2   = nn.Linear(d_ff, d_model)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.drop  = nn.Dropout(dropout)

    def forward(self, x):           # x: (B, S, 512)
        attn_out, _ = self.self_attn(x, x, x)   # → (B, S, 512)
        x = self.norm1(x + self.drop(attn_out))  # residual + norm
        ff_out = self.drop(torch.relu(self.ff1(x)))   # (B, S, 2048)
        ff_out = self.ff2(ff_out)                    # (B, S, 512)
        x = self.norm2(x + self.drop(ff_out))  # residual + norm
        return x                                  # (B, S, 512)
Parallelism: Unlike RNNs, all S positions in a sequence are processed simultaneously — the attention scores form an S×S matrix computed in one batch matrix multiply.

Decoder tensor flow

The decoder generates the output sequence token-by-token (at inference), but processes all target positions in parallel during training. It adds two extra mechanisms: a causal mask on self-attention (no peeking at future tokens) and cross-attention that queries the encoder output.

Cross-attention: where encoder meets decoder

Cross-attention Q, K, V sources: Q comes from the decoder's current representation (B, T, 512). K and V come from the encoder's final output (B, S, 512). The attention score shape is (B, H, T, S) — each target position attends over all source positions.

The causal mask

Position i may only attend to positions 0…i. The upper triangle is filled with −∞ before softmax, collapsing those weights to 0.

def subsequent_mask(size):
    # Returns (1, T, T) bool mask
    attn_shape = (1, size, size)
    mask = torch.triu(
        torch.ones(attn_shape), diagonal=1
    ).bool()
    # mask[0, i, j] = True  ↔  j > i (illegal)
    scores.masked_fill_(mask, -1e9)
    return softmax(scores / math.sqrt(d_k))

Scaled Dot-Product Attention

The core primitive. Given queries Q, keys K, and values V, compute a weighted sum of values where the weights come from a compatibility function between queries and keys.

The formula

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
Q — Query: what this position is looking for
K — Key: what this position offers
V — Value: what this position contributes when selected
√d_k — Scaling prevents dot products from growing too large (keeping softmax in a useful gradient region)
Tensor shapes (one head):
Q: [B,S,64]
K: [B,S,64]
V: [B,S,64]
QKᵀ: [B,S,S] output: [B,S,64]

Multi-Head Attention

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\ldots,\text{head}_h)\,W^O$$ $$\text{head}_i = \text{Attention}(QW_i^Q,\;KW_i^K,\;VW_i^V)$$
Why multiple heads? Each head learns to attend to different aspects (syntax, coreference, proximity…). Running 8 heads in parallel then projecting back gives the model 8 independent views of the sequence for the same compute cost as one big attention.

Positional Encoding

$$PE_{(pos,2i)} = \sin\!\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$ $$PE_{(pos,2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$
No learned parameters. Each position gets a unique 512-dim vector of sin/cos waves at different frequencies. Positions close together get similar vectors, which helps the model reason about relative distance. Shape: [max_len,512] — added to embeddings once before the first layer.
